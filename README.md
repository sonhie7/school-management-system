# 🎓 School Management System

A full-stack web application designed to simplify and centralize academic management within an educational institution. The platform provides dedicated interfaces for administrators, professors, and students to manage academic information, track performance, and organize daily educational activities.

## 📌 Project Overview

The School Management System is a web-based academic management platform developed as a Projet de Fin d'Études (PFE). It aims to reduce manual administrative tasks, improve access to academic information, and facilitate communication between the different members of an educational institution.

The application follows a client-server architecture, with a React frontend communicating with a Laravel backend API and a MySQL database.

## Features

### 👨‍💼 Administrator

Manage students and professors.

Manage academic programs, classes, and modules.

Manage exams and timetables.

Organize and maintain academic information.

Access administrative management features.

### 👨‍🏫 Professor

View assigned modules and classes.

Access student information.

Manage grades and attendance.

Share course materials.

Create assignments and manage student submissions.

### 🎓 Student

View and manage personal profile information.

Consult enrolled modules and grades.

Check attendance records.

View class timetables and export timetables to PDF.

Access course materials and assignments.

Submit assignments online.

## 🔐 Authentication and Access Control

Role-based access for administrators, professors, and students.

Protected application features based on user permissions.

API authentication using Laravel Sanctum.
